# Módulo 1 — Laboratorios

## Objetivos

Al finalizar las prácticas del módulo serás capaz de:

1. distinguir cuándo conviene utilizar reglas, búsqueda, ML, GenAI o una combinación;
2. convertir una idea de IA en un caso de uso verificable;
3. separar **modelo**, **servicio de modelo** y **aplicación empresarial**;
4. ejecutar una primera versión funcional del **Enterprise GenAI Assistant**;
5. aplicar controles deterministas alrededor de un componente probabilístico;
6. comprobar mediante pruebas que algunos riesgos deben resolverse en la aplicación, no delegarse únicamente al modelo.

## Orden recomendado

```text
M01.P01 -> M01.P02 -> M01.P03 -> M01.P04
```

M01.P03 y M01.P04 trabajan sobre la misma aplicación. Conserva los cambios realizados en P03 para continuar con P04.
