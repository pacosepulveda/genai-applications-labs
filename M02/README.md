# Módulo 2 — Fundamentos del Machine Learning

## Objetivos

En estas prácticas trabajarás el ciclo completo de un pequeño sistema de Machine Learning:

1. inspeccionar y preparar datos;
2. detectar fugas de información;
3. crear una separación de entrenamiento y evaluación;
4. establecer un baseline;
5. entrenar un clasificador supervisado;
6. evaluar el modelo con métricas adecuadas;
7. introducir un mecanismo de abstención basado en confianza;
8. aplicar un método no supervisado a telemetría;
9. integrar un modelo entrenado en **Enterprise GenAI Assistant v0.2**.

## Entorno

Todos los laboratorios están diseñados para realizarse desde el entorno web facilitado por el instructor. No es necesario instalar herramientas en el ordenador del alumno.

## Orden recomendado

```text
M02.P01 -> M02.P02 -> M02.P03 -> M02.P04 -> M02.P05
```

P02, P03 y P05 trabajan sobre el mismo problema de clasificación de solicitudes.
