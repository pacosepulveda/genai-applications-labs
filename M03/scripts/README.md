# Scripts ejecutables M03

Los notebooks del módulo contienen el mismo código dividido y explicado para clase.

Estos `.py` permiten ejecutar cada práctica completa sin copiar ni pegar código:

```bash
python scripts/m03_p01_forward_backprop.py
python scripts/m03_p02_mlp_vs_classic.py
python scripts/m03_p03_overfitting_regularization.py
python scripts/m03_p04_cnn_feature_maps.py
python scripts/m03_p05_attention_transformer.py
```

P01, P02 y P05 forman la ruta esencial. P03 y P04 son ampliación.
