# Assets del M04

Los laboratorios utilizan `sklearn.datasets.load_digits`, incluido en scikit-learn. No se requiere descargar datasets externos.

Las imágenes son de 8×8 porque permiten entrenar VAE, GAN y un pequeño denoiser de diffusion rápidamente en CPU. Su objetivo es pedagógico: comprender mecanismos, no alcanzar calidad visual de producción.
