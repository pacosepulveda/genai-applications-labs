# Scripts completos de M04

Los scripts contienen la misma lógica que los notebooks y están preparados para ejecutarse sin completar código.

Desde la raíz del repositorio:

```bash
python M04/scripts/m04_p01_image_tensors.py
python M04/scripts/m04_p02_vae_latent_space.py
python M04/scripts/m04_p03_gan_training.py
python M04/scripts/m04_p04_gan_evaluation.py
python M04/scripts/m04_p05_tiny_diffusion.py
```

`P04` reutiliza los artefactos generados por `P03`.

En clase la práctica principal es **M04.P06**. P01-P05 son ampliaciones ejecutables para inspeccionar los mecanismos internos.
