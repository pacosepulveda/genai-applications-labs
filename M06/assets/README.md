# Assets del M06

La base documental es ficticia y está diseñada para los laboratorios.

Incluye intencionadamente:

- documentación vigente;
- una versión obsoleta de `PROC-017`;
- cifras y requisitos exactos;
- identificadores como `INC-2048` y `/api/v2/status`;
- una pregunta de evaluación sin evidencia;
- un ejemplo de indirect prompt injection tratado como texto no confiable.

`retrieval_eval.jsonl` contiene el conjunto de evaluación del retriever.

`incidents.json` simula una API corporativa read-only para las prácticas de tools y agents.
