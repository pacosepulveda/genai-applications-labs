# POL-004 — Clasificación y uso de información

## 1. Niveles

La organización utiliza cuatro niveles:

- PUBLIC;
- INTERNAL;
- CONFIDENTIAL;
- RESTRICTED.

## 2. Uso con servicios de IA generativa

Los servicios de IA generativa aprobados pueden procesar información **PUBLIC** e **INTERNAL** cuando el caso de uso esté autorizado.

Información **CONFIDENTIAL** o **RESTRICTED** no debe enviarse al servicio de IA generativa general.

## 3. Credenciales

Contraseñas, claves privadas, tokens de acceso y secretos equivalentes no deben incluirse en prompts.

## 4. Trazabilidad

Los casos de uso corporativos deben permitir identificar el servicio, la versión de configuración y la política aplicada.
