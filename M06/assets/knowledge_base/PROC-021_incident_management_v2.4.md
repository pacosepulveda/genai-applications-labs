# PROC-021 — Gestión de incidentes críticos

## 1. Clasificación P1

Un incidente se clasifica como P1 cuando existe una interrupción crítica de un servicio esencial o un impacto severo y generalizado.

## 2. Acuse de recibo

El equipo de guardia debe confirmar la recepción de un incidente P1 en un máximo de **10 minutos**.

## 3. Comunicación

Mientras el P1 permanezca abierto, debe emitirse una actualización de estado al menos cada **30 minutos**.

## 4. Cierre

El cierre técnico debe registrar causa, acciones realizadas y servicios afectados.

## 5. Post-Incident Review

El informe de revisión posterior debe completarse dentro de los **5 días laborables** siguientes al cierre.
