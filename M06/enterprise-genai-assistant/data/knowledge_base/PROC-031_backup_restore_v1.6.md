# PROC-031 — Copias de seguridad y restauración

## 1. Servicios Tier-1

Los servicios clasificados como Tier-1 deben disponer de copias de seguridad verificables.

## 2. Objetivos

Para Tier-1:

- RPO objetivo: **15 minutos**;
- RTO objetivo: **2 horas**.

## 3. Pruebas

La restauración debe probarse al menos **trimestralmente**.

## 4. Evidencia

Cada prueba debe registrar fecha, sistema, resultado, duración y responsable.
