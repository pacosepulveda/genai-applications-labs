# STD-009 — Convención de identificadores operativos

## Incidentes

Los incidentes utilizan el patrón:

`INC-<número>`

Ejemplo: `INC-2048`.

## Cambios

Los cambios utilizan:

`CHG-<número>`

## Endpoint de salud

La plataforma corporativa expone el endpoint exacto:

`/api/v2/status`

para comprobaciones de estado de determinados servicios internos.
