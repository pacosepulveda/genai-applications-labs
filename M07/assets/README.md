# Assets M07

Todos los datos son ficticios y se utilizan únicamente para las prácticas del módulo.

En M07 los ficheros funcionan como **evidence pack** para table-tops y workshops de decisión. No es necesario procesarlos con Python.

| Fichero | Uso actual |
|---|---|
| `opportunity_backlog.csv` | P01 · oportunidades, pain points, fit y alternativas |
| `baseline_procedure_search.csv` | P02 · evidencia detallada del baseline del caso transversal |
| `prioritization_candidates.csv` | P02 · decisiones de portfolio |
| `data_inventory.csv` | P02/P03 · data readiness, minimización y dependencias |
| `risk_scenarios.jsonl` | P03 · risk register, controles y resiliencia |
| `enterprise_genai_assistant_case.md` | P02/P03 · caso transversal, alcance y Stage Gate |

## Cómo utilizarlos

Puedes abrir CSV, JSONL y Markdown directamente desde JupyterLab para inspeccionar la evidencia.

No se espera que escribas un script para obtener la decisión. El objetivo es poder justificarla utilizando datos, restricciones, riesgos y criterios explícitos.

## Regla del módulo

```text
la evidencia informa la decisión
la puntuación no sustituye el juicio
```

No hay datos de una organización real.
