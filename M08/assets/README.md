# Assets del M08

Todos los nombres, perfiles, organizaciones, métricas e incidentes son ficticios.

El objetivo no es encontrar una única estructura organizativa correcta, sino producir una solución defendible que:

- cubra las capacidades necesarias;
- haga explícito el ownership;
- evite responsabilidades huérfanas o duplicadas;
- adapte controles al riesgo;
- permita delivery y operación;
- incluya desarrollo de talento y cambio organizativo.
