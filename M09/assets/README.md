# Assets del M09

Todos los escenarios y cifras son didácticos.

M09 no intenta predecir qué tecnología dominará el mercado. Los assets están diseñados para practicar una disciplina de decisión:

```text
capability
→ use case
→ evidence
→ risk
→ cost
→ operability
→ decision
```

Los alumnos pueden llegar a decisiones distintas siempre que sean coherentes con la evidencia y los criterios definidos.
