# Assets M09

Todos los datos son ficticios y deliberadamente independientes de proveedores concretos.

| Fichero | Práctica | Uso |
|---|---|---|
| `technology_radar_candidates.csv` | P01 / P03 | radar, madurez y decisiones de lifecycle |
| `model_capabilities.csv` | P02 / P03 | capabilities, coste, latencia y calidad proxy |
| `adaptive_routing_requests.csv` | P02 / P03 | requests para routing adaptativo |
| `current_architecture_metrics.csv` | P02 / P03 | baseline operativo para comparar decisiones |
| `future_scenarios.json` | P03 | cuatro futuros para stress test |
| `enterprise_genai_assistant_v10_case.md` | P03 | baseline autocontenido del caso final |
| `v10_component_candidates.csv` | P03 | lifecycle board de componentes |

Los ficheros funcionan como **evidence packs**. No es necesario procesarlos con notebooks: pueden leerse directamente desde GitHub/SageMaker y utilizarse para justificar decisiones en las plantillas Markdown.
