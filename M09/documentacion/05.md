# 263. Cierre del curso

M01 comenzó con:

```text
¿Qué es IA generativa
y dónde aporta valor?
```

M09 termina con:

```text
¿Cómo construimos una organización
que siga tomando buenas decisiones
cuando la tecnología cambie?
```

El recorrido completo ha sido:

```text
M01  Foundations + enterprise use case
 ↓
M02  Machine Learning
 ↓
M03  Deep Learning
 ↓
M04  Generative Vision
 ↓
M05  Generative NLP
 ↓
M06  RAG + LangChain + Agents
 ↓
M07  Strategy + Value + Risk
 ↓
M08  Team + Operating Model
 ↓
M09  Technology Foresight + Adaptation
```

La conclusión no es:

```text
"la IA sustituirá todo"
```

ni:

```text
"debemos adoptar cada nueva tecnología"
```

La conclusión es más útil:

> construir capacidades para experimentar, medir, gobernar y adoptar únicamente aquello que mejora de forma demostrable nuestros sistemas, nuestros procesos y la colaboración entre personas y tecnología.
