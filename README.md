# GenAI Applications Labs

Laboratorios del curso **Desarrollo de Aplicaciones de IA Generativa**.

El repositorio está organizado por módulos. Los laboratorios están diseñados para construir de forma progresiva una aplicación denominada **Enterprise GenAI Assistant** y, al mismo tiempo, practicar decisiones de arquitectura, evaluación, seguridad y gobierno.

## Módulo 1 — Introducción: IA y su uso en la empresa

| Lab | Título | Duración | Tipo |
|---|---|---:|---|
| M01.P01 | ¿IA, ML, GenAI o software convencional? | 20 min | análisis + notebook |
| M01.P02 | Caso de uso y criterios de éxito | 25 min | análisis + notebook |
| M01.P03 | Enterprise GenAI Assistant v0.1 | 55 min | desarrollo guiado |
| M01.P04 | Red Team básico y hardening | 20 min | seguridad + pruebas |

> Los laboratorios del repositorio contienen **enunciados y material de partida**, no las soluciones del instructor.

## Requisitos generales

- Python 3.11 o 3.12 recomendado.
- Git.
- Un editor como VS Code.
- Docker Desktop o Docker Engine, opcional para el paso de despliegue.
- Para M01.P03 se puede trabajar completamente en `mock`; el acceso a un proveedor LLM real es opcional.

## Uso

```bash
git clone https://github.com/pacosepulveda/genai-applications-labs.git
cd genai-applications-labs
```

Consulta `M01/README.md` para el primer módulo.
