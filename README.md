# GenAI Applications Labs

Laboratorios del curso **Desarrollo de Aplicaciones de IA Generativa**.

El repositorio está organizado por módulos y está diseñado para construir de forma progresiva una aplicación denominada **Enterprise GenAI Assistant**, combinando desarrollo, arquitectura, evaluación, seguridad y gobierno.

## Entorno de laboratorio

Los laboratorios están preparados para realizarse **completamente desde el navegador**.

El instructor facilitará el acceso al entorno de laboratorio y, cuando sea necesario, las credenciales o permisos para utilizar servicios de IA y recursos cloud. No es necesario instalar herramientas de desarrollo en el ordenador del alumno.

## Proyecto transversal

A lo largo del curso, **Enterprise GenAI Assistant** evolucionará de una primera API controlada hacia una aplicación corporativa más completa, incorporando progresivamente capacidades de Machine Learning, modelos de lenguaje, procesamiento documental, recuperación de información, herramientas, orquestación, evaluación y controles de producción.
